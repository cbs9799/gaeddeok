# 개떡찰떡 (gaeddeok)

개떡같이 말해도 찰떡같이 알아먹는다. 두서없는 아이디어를 정리해주는 플러그인.

## 두 가지 모드

| 명령 | 하는 일 | 출력 대상 |
|------|---------|-----------|
| `/gaeddeok:idea <주저리>` | 생각을 구조화된 기획 브리프로 정리 | 사람 (생각 정리용) |
| `/gaeddeok:prompt <주저리>` | AI에 바로 붙여넣을 프롬프트로 정리 | 기계 (LLM용) |

스킬은 슬래시 없이도 자동 발동한다. "이거 정리해줘", "프롬프트로 만들어줘" 같은 말에 반응.

## 사용 예

```
/gaeddeok:idea 어 동네 사람들끼리 남는 음식 나누는거 하고싶은데 앱인지 단톡인지...
/gaeddeok:prompt 유튜브 채널 팔건데 게임 좋아하고 숏폼 알고리즘 타는법 물어볼 프롬프트
```

## 스킬 조합 (prompt 모드, v0.2.0~)

프롬프트 대상이 Claude(Code/Cowork/claude.ai)면, 실행 환경에 설치된 스킬 목록에서 작업 단계(계획→구현→검증→배포)에 맞는 스킬을 1~4개 골라 `[Skill plan]` 섹션으로 프롬프트에 넣는다. ChatGPT 등 외부 LLM 대상이면 생략. 목록에 없는 스킬은 지어내지 않는다.

## 공통 원칙

되묻지 않는다. 빈칸은 가장 그럴듯한 값으로 추측해 채우고, "가정한 것"으로 노출한다. 틀린 가정만 사용자가 잡으면 된다. 질문 많으면 개떡찰떡 가치가 죽는다.

## 구성

- `skills/gaeddeok-idea/` — 아이디어 → 구조화 브리프
- `skills/gaeddeok-prompt/` — 아이디어 → LLM 프롬프트
- `commands/idea.md`, `commands/prompt.md` — 슬래시 명령
